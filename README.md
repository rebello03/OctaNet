# ATM Interface Simulation - OctaNet Python Internship (Task 1)

A console-based ATM Machine simulation built with Python using Object-Oriented Programming (OOP) principles. This project was created as part of the **OctaNet Services Pvt Ltd** Python Development Internship.

## Features

* **PIN Authentication:** Validates a 4-digit user PIN with a maximum of 3 login attempts before blocking access.
* **Balance Inquiry:** Displays the current available account balance.
* **Cash Deposit:** Allows users to deposit positive amounts with input validation.
* **Cash Withdrawal:** Processes withdrawals while checking for sufficient funds.
* **Fund Transfer:** Enables transfers to valid 6+ digit recipient account numbers.
* **Transaction History:** Logs and displays all activities performed during the session.
* **PIN Change:** Lets users securely update their 4-digit PIN after verifying their current PIN.

## Technologies Used

* **Language:** Python 3.x
* **Standard Libraries:** `sys`, `time`
